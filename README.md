# FsInfoCat

Filesystem content information cataloging and analysis tool

Refer to [WIKI pages](https://github.com/lerwine/FsInfoCat/wiki) for more information.

## Projects

- [FsInfoCat](src/FsInfoCat/README.md): Platform-independent base assembly.
- [FsInfoCat.Generator](src/FsInfoCat.Generator): Code generation for the base FsInfoCat assembly.
- [FsInfoCat.Local](src/FsInfoCat.Local/README.md): Windows-64 implementation for local database.
- [FsInfoCat.Upstream](src/FsInfoCat.Upstream/README.md): Windows-64 implementation for remote databases.
- [FsInfoCat.PS](src/FsInfoCat.PS/about_FsInfoCat.help.txt): PowerShell FsInfoCat module.
- [FsInfoCat.Desktop](src/FsInfoCat.Desktop): Desktop FsInfoCat application.
- [FsInfoCat.UnitTests](src/FsInfoCat.UnitTests): Unit tests for solution.
- [DevUtil](src/DevUtil): PowerShell module and scripts to assist with software development for this project.
